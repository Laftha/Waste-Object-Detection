# Waste Object Detection

A computer vision project designed to detect and classify waste objects, supporting automated recycling and environmental cleanup initiatives. This repository includes trained model weights to help power object detection pipelines for waste sorting systems.

## Project Overview

Proper waste management and recycling rely heavily on efficient sorting. This project leverages deep learning and computer vision to identify and categorize various types of waste items from images or video streams, streamlining the recycling process.

## Repository Contents

- **`best.pt`**: The trained model weights file used for inference and object detection.
